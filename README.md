# JavaScript/TypeScript 코딩 테스트

## 1. debounce 구현

입력 함수와 delay를 받아, delay 시간 안에 여러 번 호출되면 마지막 호출만 실행되도록 하는 debounce 함수를 구현하라. this와 arguments를 유지해야 한다.

> closure / this 바인딩

## 2. 배열 불변 업데이트

객체 배열이 주어질 때, 특정 id를 가진 요소의 값을 변경하되 원본 배열을 변경하지 않고 새로운 배열을 반환하라.

## 3. Optional Chaining / Nullish Coalescing

중첩 객체에서 특정 값이 있으면 사용하고, 없으면 기본값을 사용하라. if 문 없이 한 줄로 작성하라.

## 4. groupBy 구현

객체 배열과 key를 받아, 해당 key 기준으로 그룹핑된 객체를 반환하라. 제네릭을 사용해 타입 안정성을 유지하라.

## 5. Promise 병렬 처리

두 개 이상의 비동기 함수를 순차가 아닌 병렬로 실행하고, 결과를 하나의 객체로 반환하라.

## 6. 이벤트 버블링 제어

중첩된 DOM 구조에서 특정 요소 클릭 시, 부모 요소의 클릭 이벤트가 실행되지 않도록 처리하라.

## 7. 얕은 복사 vs 깊은 복사 (설명형)

객체를 얕은 복사했을 때 발생하는 문제를 설명하라. 깊은 복사를 안전하게 수행하는 방법을 2가지 설명하라.

## 8. this 바인딩 문제

메서드를 변수에 할당해 호출했을 때 this가 어떻게 동작하는지 설명하라. 문제를 해결하는 방법을 2가지 제시하라.

## 9. TypeScript Narrowing

유니온 타입이 주어졌을 때, 타입에 따라 다른 로직을 수행하도록 구현하라. 타입 안전성을 보장해야 한다.

## 10. 제네릭 유틸 함수

id를 가진 객체 배열에서 특정 id의 요소를 찾는 함수를 구현하라. 제네릭을 사용해 타입을 유지하라.
