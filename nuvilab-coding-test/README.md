# 🍱 누비랩 프론트엔드 라이브 코딩 연습

누비랩 면접 스타일의 **점진적 제약 추가** 라이브 코딩 문제 4세트입니다.
각 문제는 3단계(STEP)로 구성되어 있으며, 단계가 올라갈수록 제약이 추가됩니다.

---

## 🚀 시작하기

```bash
# 별도 설치 필요 없음! Node.js만 있으면 됩니다. (v14+)

# 문제별 실행
node problem1.js   # 음식 데이터 파서
node problem2.js   # 급식 잔반 데이터 집계
node problem3.js   # 프론트엔드 유틸리티 구현
node problem4.js   # 식단 최적화 알고리즘
```

---

## 📋 문제 구성

| # | 제목 | 난이도 | 핵심 역량 | 시간 |
|---|------|--------|----------|------|
| 1 | 음식 데이터 파서 | ★★☆ | 문자열 파싱, 트리, DFS | 40분 |
| 2 | 급식 잔반 데이터 집계 | ★★☆ | reduce, Promise.allSettled, diff | 35분 |
| 3 | 프론트엔드 유틸리티 구현 | ★★★ | debounce, 가상스크롤, 재연결 | 45분 |
| 4 | 식단 최적화 알고리즘 | ★★★ | 백트래킹, 점수화, 그리디 | 35분 |

### 문제 1: 음식 데이터 파서
- **STEP 1** — 중첩 문자열 → 트리 객체 파싱 (재귀 하강 파서)
- **STEP 2** — 트리 역순 변환 + 문자열 출력 (immutable)
- **STEP 3** — 트리에서 경로 검색 (DFS)

### 문제 2: 급식 잔반 데이터 집계
- **STEP 1** — 급식소별 잔반량 집계 (reduce, groupBy)
- **STEP 2** — 병렬 API 호출 + 실패/타임아웃 처리 (Promise.allSettled)
- **STEP 3** — 어제 vs 오늘 변화 감지 (Set 차집합)

### 문제 3: 프론트엔드 유틸리티 구현
- **STEP 1** — debounce 함수 (클로저 + cancel)
- **STEP 2** — 가상 스크롤 인덱스 계산기 (overscan 포함)
- **STEP 3** — 자동 재연결 로직 (지수 백오프)

### 문제 4: 식단 최적화 알고리즘
- **STEP 1** — 목표 칼로리에 가장 가까운 조합 (백트래킹)
- **STEP 2** — 영양소 비율 점수 계산 (비율 비교)
- **STEP 3** — 대량 데이터용 그리디 최적화 (O(n log n))

## 📝 풀이 방법

1. 각 `problem*.js` 파일을 열기
2. `✏️ 여기에 코드를 작성하세요` 부분에 코드 작성
3. `node problem*.js`로 실행하여 테스트 결과 확인
4. 모든 테스트가 ✅ 초록색이 되면 통과!

```
  ✅ TC1: 기본 메뉴 파싱
  ✅ TC2: 깊은 중첩 파싱
  ❌ TC3: 단일 항목        ← 이 부분을 고치세요!
  ✅ TC4: 복잡한 중첩
```

## 💡 면접 팁

1. **바로 코딩하지 마세요** — 문제를 다시 말로 정리
2. **엣지 케이스 먼저 언급** — 빈 배열, null, 단일 항목
3. **brute force → 최적화** — 동작하는 코드 먼저
4. **사고 과정을 말하세요** — 면접관은 과정을 봅니다
5. **변수명은 의미있게** — 읽기 쉬운 코드가 합격 코드
